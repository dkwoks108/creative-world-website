### 2. TECHNICAL ARCHITECTURE & DEVELOPMENT RULES

- **Framework**: Next.js App Router, React, Strict TypeScript.
- **Styling**: Tailwind CSS + CSS Variables (`:root`).
- **Motion**: GSAP 3 + ScrollTrigger + Lenis Smooth Scroll.
- **3D Render Layer**: Three.js / React Three Fiber (dynamic import lazy loaded).
- **Accessibility Target**: WCAG 2.1 AA Compliance.
- **Performance Budget**: Target Core Web Vitals (LCP < 2.2s, CLS < 0.05, INP < 150ms).
